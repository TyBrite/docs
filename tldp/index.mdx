---

TLDP (the Tybrite Logistics Developer Platform) gives you a single, versioned
API in front of many courier companies. Integrate once and you can quote rates,
create and fulfil orders, track deliveries in realtime, capture proof of
delivery, run returns and exchanges, and receive webhooks — without managing a
relationship with each carrier.

## Two ways to integrate

- **REST API** — call `https://api.tybritelabs.com/logistics/v1` directly. See the
  [API Reference](/tldp/api-reference/introduction).
- **TypeScript SDK** — `@tybrite-labs/tldp-sdk`, a fully typed client. See the
  [SDK guide](/tldp/sdk/introduction).

## Base URL

```
https://api.tybritelabs.com/logistics/v1
```
