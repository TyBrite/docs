**Anvil** turns a plain-language description of a store into a complete, deployed storefront,
already wired to your Galactic Core catalog, cart, checkout, payments, search, and the rest of the
SDK — the layer that sits on top of this API, generated rather than hand-built.

## What it generates against

Everything documented here — the [TypeScript SDK](/sdk/introduction), the service surface, the
conventions in [Core Concepts](/concepts) — is the same surface Anvil generates against. A
storefront it produces calls the documented methods (`client.products.listProducts`,
`client.orders`, `client.payments`, `client.search`, recommendations, analytics, multi-currency
pricing) exactly as hand-written integration code would.

## When to reach for it

- You want a storefront live quickly without writing the integration plumbing first.
- You're prototyping a concept and want a real, data-backed store to react to.
- You're a partner who wants to offer customers an AI-generated storefront on top of their own
  Galactic Core backend.

Building by hand is equally supported, from the [Quickstart](/quickstart) and the
[TypeScript SDK](/sdk/introduction). Both routes end up on the same API surface, so a generated
storefront and a hand-written one are extended the same way.
